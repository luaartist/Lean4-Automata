\section{Full Scan Pipeline}
Five phases: discover $\to$ import pass $\to$ symbol pass $\to$ dependency
pass $\to$ finalise.  All within a single PG transaction per batch.

\section{File Watcher}
Long-running daemon; debounce 500\,ms; SHA-256 hash gate; transactional
update; cache invalidation; optional dependent notification.

\section{Wolfram Service \emph{[Optional -- Non-Core]}}
Shells out to \texttt{wolframscript}; stores result in
\texttt{symbols.metadata} JSONB.  No other service depends on it.
