\section{Kubernetes Resources}
Query API: 3 replicas, 250\,m--1 CPU, 256--512\,Mi.
Workers: 4 replicas, 500\,m--2 CPU, 512\,Mi--1\,Gi.

\section{Zero-Downtime Deploy}
Rolling update (\texttt{maxUnavailable: 0}, \texttt{maxSurge: 1}).
Readiness probe: \texttt{GET /health}.  Liveness: same, 30\,s initial delay.
Migrations run as a Kubernetes Job before deployment.

\section{Backup}
Daily \texttt{pg\_dump} to object storage; WAL archiving for PITR.
Redis: no backup (ephemeral).
