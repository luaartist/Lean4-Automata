\chapter{Backend Performance}

\section{Connection Pooling}
\texttt{asyncpg} pool: \texttt{min\_size=10}, \texttt{max\_size=50},
\texttt{command\_timeout=30\,s}.  For $>$\,50 concurrent replicas, introduce
PgBouncer in transaction-pooling mode.

\section{Query Optimisation}
Transitive dependencies via recursive CTE with depth cap.  Full-text
search via GIN index on \texttt{to\_tsvector}.  Batch inserts via
\texttt{executemany} in batches of 500 rows.
