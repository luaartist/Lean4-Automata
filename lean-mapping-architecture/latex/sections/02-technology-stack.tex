\section{Key Trade-offs}

\begin{itemize}
  \item \textbf{PostgreSQL over MongoDB}: referential integrity for dependency
        graphs outweighs schema flexibility.
  \item \textbf{Redis as ephemeral cache only}: on total cache loss, the system
        degrades to DB queries---no data is lost.
  \item \textbf{Neo4j deferred}: recursive CTEs sufficient for depth~$\leq$\,10;
        adopt Neo4j only if interactive graph exploration becomes a priority.
\end{itemize}
