\section{Data Flows}

\textbf{Read path:} Client $\to$ LB $\to$ Query API $\to$ Redis (L1).
On miss: PostgreSQL query, cache result, return with freshness metadata.

\textbf{Incremental write:} FS event $\to$ File Watcher (debounce 500\,ms)
$\to$ hash check $\to$ transactional update (delete old, insert new)
$\to$ invalidate Redis $\to$ optionally enqueue dependent file checks.

\textbf{Full scan write:} Ingestion API $\to$ Celery task $\to$ five-phase
pipeline (discover, imports, symbols, dependencies, finalise)
$\to$ update \texttt{index\_runs}.
