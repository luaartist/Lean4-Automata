\chapter{Observability}

\section{Three Pillars}
\textbf{Metrics}: Prometheus + Grafana.
\textbf{Logs}: structured JSON to stdout.
\textbf{Traces}: OpenTelemetry $\to$ Jaeger.

\section{Correlation IDs}
Every request carries \texttt{X-Request-ID}---attached to all log lines,
propagated to Celery tasks, returned in responses and error envelopes.
