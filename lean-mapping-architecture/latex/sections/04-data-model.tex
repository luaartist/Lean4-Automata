\section{Indexing Strategy}

\begin{itemize}
  \item B-tree on \texttt{symbols(full\_name)} for $O(1)$ lookup.
  \item GIN on \texttt{symbols(attributes)} for JSONB containment.
  \item GIN/tsvector on \texttt{symbols(docstring || name)} for FTS.
  \item Composite B-tree on \texttt{dependencies(source, target)}.
\end{itemize}

\section{Materialised Views}

\textbf{dependency\_stats}: per-symbol dependency count, usage count, centrality score.
\textbf{module\_metrics}: per-module symbol count by kind, average length.
Both refreshed concurrently on an hourly schedule.

\section{Migration Strategy}

Alembic manages schema versions.  Every migration is forward-only in
production, tested in CI, and backwards-compatible for one release cycle.
